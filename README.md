## 📥 Download & Install (Free — No Play Store Needed)

1. Go to **[Releases](https://github.com/itssaadihere-web/GharSync/releases/latest)**
2. Download `GharSync-*.apk`
3. On phone: **Settings → Security → Unknown Sources → Enable**
4. Open APK → Install → Done ✅

## 🧠 AI Parser (Works Offline)

Type grocery items in any language:
- Urdu: `"دو کلو آلو"` → Aloo, 2 kg, Vegetables
- Roman Urdu: `"2 kilo aloo chahiye"` → Aloo, 2 kg, Vegetables
- English: `"2 kg potatoes"` → Potatoes, 2 kg, Vegetables
